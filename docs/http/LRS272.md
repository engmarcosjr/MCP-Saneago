## Protocolo

As regras gerais do ZK por HTTP (onChange+onClick no mesmo POST, `echo` com
`opt=i`, reuso do `dtid`, queda de sessao) estao em `docs/HTTP-ECO707-ECO709.md`.
Elas valem para qualquer tela — mas o payload concreto so esta confirmado nas telas
com status `REPLICADO`.
