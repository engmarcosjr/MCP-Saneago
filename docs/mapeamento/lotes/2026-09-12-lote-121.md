Acessada via fallback no menu corporativo (*ATENDIMENTO AO CLIENTE -> Portal de Atendimento -> Atendimento*). Tela confirmada sem campos interativos e sem botões de ação na tela inicial. Classificada como `sem_campos_confirmado`.
- **EGWV001:** Contrato Comercial (`https://www.saneago.com.br/prt/egw/EGW001CadastroContratoComercial.zul`). Acessada via fallback no menu corporativo (*Grandes Clientes Web -> Cadastro -> Contrato Comercial*). Classificada como `somente_leitura`.
