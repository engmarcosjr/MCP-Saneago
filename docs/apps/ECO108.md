# ECO108 - Relação de contas potencial faturamento

## Categoria
Comercial e Atendimento ao Cliente

## Tipo
Leitura e Consulta (misto)

## O que faz
Permite consultar a relação de contas de potencial faturamento com filtros por cidade, bairro, distrito, logradouro, grupo de faturamento e rota.

## URL Real / Atalho Direto
- `https://www.saneago.com.br/prt/eco/ECO108ListarContasPotenFaturamento.zul`

## Campos e Filtros da Tela
- **Cidade** (`text` / editável): Código da cidade.
- **Cidade** (`text` / readonly): Descrição da cidade.
- **Bairro** (`text` / editável): Código do bairro.
- **Bairro** (`text` / readonly): Descrição do bairro.
- **Distrito** (`text` / editável): Código do distrito.
- **Distrito** (`text` / readonly): Descrição do distrito.
- **Logradouro** (`text` / editável): Código do logradouro.
- **Logradouro** (`text` / readonly): Descrição do logradouro.
- **Grupo de Faturamento** (`text` / editável): Código do grupo de faturamento.
- **Rota** (`text` / editável): Código da rota.
- **Sim** (`radio` / editável): Opção Sim para filtro de subcategorias.
- **Não** (`radio` / editável): Opção Não para filtro de subcategorias.
- **Sim** (`radio` / editável): Opção Sim adicional.
- **Não** (`radio` / editável): Opção Não adicional.

## Botões Disponíveis
- **Consultar**: Executa a pesquisa de contas de potencial faturamento.
- **Cancelar**: Limpa os filtros informados na tela.
