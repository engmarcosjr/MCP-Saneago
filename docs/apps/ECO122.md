# ECO122 - Manutenção de Bairros

## Categoria
Comercial e Atendimento ao Cliente

## Tipo
Leitura e Consulta (misto)

## O que faz
Permite consultar informações cadastrais e parâmetros de manutenção de bairros (coleta/tratamento de esgoto, cidade emissão, distrito, consumo mínimo).

## URL Real / Atalho Direto
- `https://www.saneago.com.br/prt/eco/ECO122ManutencaoBairro.zul`

## Campos e Filtros da Tela
- **Cidade** (`text` / editável): Código da cidade (maxlength 4).
- **Cidade** (`text` / readonly): Descrição da cidade.
- **Bairro** (`text` / readonly): Código do bairro (maxlength 4).
- **Bairro** (`text` / readonly): Descrição do bairro.
- **Informar % para contas S/N** (`combobox` / editável): Informar percentual para contas Sim/Não.
- **Nome** (`text` / readonly): Nome do bairro (maxlength 30).
- **Distrito** (`text` / readonly): Código do distrito (maxlength 5).
- **Distrito** (`text` / readonly): Descrição do distrito.
- **Cidade Emissão** (`text` / readonly): Código da cidade de emissão (maxlength 4).
- **Cidade Emissão** (`text` / readonly): Descrição da cidade de emissão.
- **Coleta Esgoto (S/N)** (`text` / readonly): Indicador de coleta de esgoto Sim/Não (maxlength 1).
- **Tratamento Esgoto (S/N)** (`text` / readonly): Indicador de tratamento de esgoto Sim/Não (maxlength 1).
- **% Coleta Esgoto** (`text` / readonly): Percentual de coleta de esgoto (maxlength 3).
- **% Tratamento Esgoto** (`text` / readonly): Percentual de tratamento de esgoto (maxlength 3).
- **Consumo Mínimo** (`text` / readonly): Consumo mínimo cadastrado (maxlength 3).
- **Sintético** (`radio` / editável): Opção de exibição sintética.
- **Analítico** (`radio` / editável): Opção de exibição analítica.
