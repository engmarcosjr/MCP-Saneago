# LRS734 - Atendimento Por Código de Serviço

## Categoria
Logística, Redes e Serviços de Campo / Saneago

## Tipo
Leitura e Relatório (jsp)

## O que faz
Permite a emissão e visualização de relatório de serviços atendidos por código de serviço em determinado período.

## URL Real / Atalho Direto
- `https://www.saneago.com.br/prt/lrs/LRS734relAtendCod.jsp`

## Campos e Filtros da Tela
- **Periodo** (dataInicio: input de texto, editável, max 10)
- **Periodo** (dataFim: input de texto, editável, max 10)
- **Serviço** (codigoServico: input de texto, editável, max 7)
- **Serviço** (descricaoServico: input de texto, readonly, max 40)

## Botões Disponíveis
Nenhum botão detectado na tela inicial.

## Observações de Segurança e Automação
- Tela JSP de consulta e emissão de relatório operacional por código de serviço.
- Não contém botões diretos de gravação ou alteração de dados.
