# MTGV002 - Enviar Retorno

## Categoria
Financeiro, Tesouraria e Remessas

## Tipo
Formulário de Escrita / Upload (zk)

## O que faz
Permite realizar o upload e envio de arquivos de retorno de leitura, reaviso, contas retidas e entregas alternativas para processamento no sistema.

## URL Real / Atalho Direto
- `https://www.saneago.com.br/prt/mtg/MTG002EnviarRetorno.zul`

## Campos e Filtros da Tela
- **Entrega Alternativas** (`file` / editável): Seleção de arquivo de retorno para envio.

## Botões Disponíveis
- **Adicionar arquivo(s) de retorno**: Seleciona e adiciona arquivos de retorno para upload.

### Botões Ignorados
- **Sem Rotulo** (`submit` / id `g39P5-a`): Acionador interno de submissão do formulário.

## Colunas do Resultado
- Sequenciais Esperados
- Distrito
- Leitura/Reaviso
- Retidas
- Entrega Alternativas
- Nome do Arquivo
- Status / Erro
- Ação

## Perguntas que Responde
- "enviar arquivo de retorno de leitura no MTGV002"
- "fazer upload de arquivo de retorno de entrega alternativa"
- "acompanhar status de arquivos de retorno enviados"
