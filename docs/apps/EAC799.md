# EAC799 - Aplicação Restrita / Não Disponível

## Categoria
Atendimento Comercial / Módulo EAC

## Tipo
Sem Acesso / Restrita ao Perfil Atual

## O que faz
Aplicação listada no catálogo corporativo, porém **não disponível** para o perfil de acesso atual no portal ZK (não exibida nos resultados de busca rápida nem na árvore hierárquica do menu).

## URL Real / Atalho Direto
- `N/A` (Inacessível via menu do perfil)

## Status de Acesso
- **Acesso Confirmado**: Não (perfil sem permissão de acesso ou aplicação legada/desativada).
