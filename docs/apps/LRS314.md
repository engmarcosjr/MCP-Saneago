# LRS314 - Análise tempo padrão/execução/perfomance

## Categoria
Logística, Redes e Serviços de Campo / Saneago

## Tipo
Leitura e Relatório (jsp)

## O que faz
Permite a emissão e visualização de relatório de análise de tempo padrão, execução e performance de equipes por período e unidade organizacional.

## URL Real / Atalho Direto
- `https://www.saneago.com.br/prt/lrs/LRS314relTempPad.jsp`

## Campos e Filtros da Tela
- **Período** (dataInicial: input de texto, editável, max 10)
- **Período** (dataFinal: input de texto, editável, max 10)
- **Unidade** (codigoUnidadeOrganizacional: input de texto, editável, max 5)
- **Unidade** (nomeUnidadeOrganizacional: input de texto, readonly)
- **Equipe** (codigoEquipe: input de texto, editável, max 4)
- **Equipe** (descricaoEquipe: input de texto, readonly, max 25)

## Botões Disponíveis
Nenhum botão detectado na tela inicial.

## Observações de Segurança e Automação
- Tela JSP de consulta e emissão de relatório operacional/estatístico.
- Não contém botões diretos de gravação ou alteração de dados.
