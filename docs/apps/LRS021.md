# LRS021 - Extravasamento de Esgoto

## Categoria
Logística, Redes e Serviços de Campo / Saneago

## Tipo
Leitura e Relatório (jsp)

## O que faz
Permite a emissão e visualização de relatório de extravasamento de esgoto sanitário por regional e mês/ano de referência.

## URL Real / Atalho Direto
- `https://www.saneago.com.br/prt/lrs/LRS021extravaza.jsp`

## Campos e Filtros da Tela
- **LRS 021** (ano_ref: input de texto, editável, max 4)
- **LRS 021** (mes_ref: input de texto, editável, max 2)
- **LRS 021** (cd_regional: input de texto, editável)
- **LRS 021** (no_regional: input de texto, readonly)
